# i18n

`packages/shared/src/i18n/` (`@subby/shared/i18n`): our own small i18n, no library (shared needs it too, and Hermes' `Intl.PluralRules` isn't relied on).

- `en.ts` is the source catalog: flat dotted keys by area (`'home.tapSleep'`), `{name}` placeholders, `{ one, other }` plurals picked by `{count}` (`pluralCategory`: French and Portuguese count 0 as one). `t(key, params)` formats number params for the language, so pass years and ids as strings.
- Other languages (`de`, `es`, `fr` (vous, French spacing), `it`, `nl`, `ptBR`; German, Spanish, Italian and Dutch use du/tú/tu/je, Portuguese você) go in `catalogs.ts` (`TRANSLATIONS`, every language required), typed `Translation` (every English key). A new English key needs all six translations, or typecheck fails. A missing key falls back to English at runtime.
- The translations were model-drafted and reviewed (back-translation of the `review.ts` texts, plus a Gemini pass); the user settled German and Dutch and accepted the rest. Adjust from user feedback; give new `review.ts` texts the same back-translation check.
- `i18n.test.ts` checks keys, placeholders and plurals per language, and that `review.ts` (`REVIEW_KEYS`: safety texts a native speaker reviews per language) only names keys that exist.
- `formatNumber`, `formatDate(ms, Intl options)`, `formatClock(ms, clock)` use the current locale; never `toLocaleString([])` or `toLocaleDateString([])`.
- Shared domain text goes through `t()` too (durations, ages, reminders, family alerts, milestones (`label` is a getter), story, feed/diaper summaries, backup and invite errors). Percentile ordinals: English computes "50th", other catalogs wrap the number in `percentile.*`.
- Stays English: CSV headers (decided), the diagnostics report, server error messages, the dev tools in `SyncAccess`.

## In the app (`apps/mobile/features/i18n.ts`)
- `settings.language` (`'system'` or a locale, device-local) is applied at hydrate (headless runs too, so notifications are planned in it) and on change; `expo-localization` gives the phone's language (its plugin declares `supportedLocales`, so Android 13+ and iOS list Subby in per-app language settings).
- The root `Stack` is keyed by the locale, so a change re-renders every screen (navigation stays). Settings → Language uses `components/LanguagePicker.tsx` (names in their own language).
- `features/strings.test.ts` fails on English left in `app/`, `components/`, `features/`, `store/` (JSX text and capitalized quoted strings; `// i18n-ignore` at a line's end for non-UI strings; `ENGLISH` lists files that stay English).
